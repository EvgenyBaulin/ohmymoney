# Приложение: формат базы данных, версия 1

Эта страница описывает файл базы `finance.sqlite` (SQLite 3.37 или новее) так, чтобы его можно было прочитать без приложения: любым клиентом SQLite или скриптом. Это же описание лежит рядом с каждой копией базы в «Настройки → Бэкапы». Формат архива переноса и файлов CSV — в [formats.md](formats.md).

Схема меняется только вперёд: новые версии приложения добавляют таблицы и столбцы миграциями (`Schema/000N_*.sql`) и ничего не переименовывают и не убирают. Сейчас в схеме 15 миграций (`schemaVersion` 15); список применённых — в таблице `grdb_migrations`. Разовых хитростей нет: всё, от чего зависят цифры приложения, лежит в этих таблицах.

## Соглашения

- **Идентификаторы** — UUID текстом, заглавными буквами. Исключения: у `currencies`, `custom_currencies` и `settings` ключ — код валюты или строка-ключ, у `rates` — пара (день, валюта).
- **Деньги** — целые числа в единицах 1/10 000 (столбцы с суффиксом `_e4`): 250 ₽ хранятся как `2500000`. В CSV такой столбец называется без `_e4`, а сумма записана десятичной строкой с точкой. Курсы и ставки — десятичные строки (`95.5`), потому что число с плавающей точкой для денег не годится.
- **Знак — это вид.** Сумма операции и каждая её часть больше нуля; расход это или доход, говорит `kind`.
- **Моменты** — строки в UTC; **дни** — `YYYY-MM-DD`; **месяцы** — `YYYY-MM`.
- **Булевы значения** — `0` и `1`.
- **Мягкое удаление.** Операции, долги и сценарии не стираются сразу: у них есть `deleted_at`. Отмена шага (⌘Z) возвращает запись.
- **Внешние ключи** включены на каждом соединении. Операции, которые пишет само приложение, различаются по `transactions.external_id` (`sched:`, `reimb:`, `reconcile:`, `transfer:`, `writeoff:`, `debtinterest:`, `debtmarkup:`, `debtcost:`, `instreturn:`, `pledgeloss:`, `ccinterest:`, `npd:`, `tax:`, `alloc:`).
- **Остатки не хранятся.** Остаток счёта — последняя сверка плюс движения после неё; остаток долга — сумма журнала. Хранится то, из чего они считаются.

## Таблицы

Описания столбцов ниже написаны по смыслу; тест проверяет, что каждая таблица и каждый столбец схемы здесь названы, — забытое новой миграцией роняет тест.

### `account_groups`

Группы счетов: «Наличные», «Банки», «Накопления»… Группа может не входить в сводку («не в сводке»).

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `name` | TEXT, обязательно | название |
| `in_summary` | INTEGER, обязательно | 1 — счета группы входят в сводку («Всего», «Можно тратить»); 0 — «не в сводке» |
| `sort` | INTEGER, обязательно | порядок в списках (меньше — выше) |
| `archived` | INTEGER, обязательно | 1 — в архиве: не предлагается, но остаётся в операциях и отчётах |

### `allocation_rules`

Правила распределения дохода: сколько процентов или какую сумму предложить отложить на цель или на подушку. Правила только предлагают, ничего не записывают.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `target` | TEXT, обязательно | куда: в цель, на счёт или в подушку; значения: `goal`, `account`, `cushion` |
| `goal_id` | TEXT | цель (для `target = goal`); ссылка на `goals` |
| `payment_method_id` | TEXT | счёт подушки (для `target = cushion`); ссылка на `payment_methods` |
| `mode` | TEXT, обязательно | как считать: процент от базы или фиксированная сумма; значения: `percent`, `fixed` |
| `percent` | TEXT | процент от базы, десятичная строка (с копейками) |
| `amount_e4` | INTEGER | фиксированная сумма в `currency` |
| `currency` | TEXT | валюта фиксированной суммы |
| `sort` | INTEGER, обязательно | порядок правил |
| `active` | INTEGER, обязательно | 1 — правило предлагается |

### `anomaly_dismissals`

Аномалии, про которые владелец сказал «Это нормально»: пара (правило, предмет).

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `rule` | TEXT, обязательно | правило аномалии (одно из семи) |
| `transaction_id` | TEXT | операция, про которую сказано «Это нормально»; ссылка на `transactions` |
| `at` | TEXT, обязательно | когда скрыто |
| `subject` | TEXT | предмет аномалии (подписка, категория и т. п.) |

### `asset_valuations`

Оценки имущества на день; последняя оценка не позже дня и есть стоимость на этот день.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `asset_id` | TEXT, обязательно | имущество, которое оценено; ссылка на `assets` |
| `day` | TEXT, обязательно | день оценки |
| `value_e4` | INTEGER, обязательно | стоимость в валюте имущества |
| `note` | TEXT | комментарий |

### `assets`

Имущество для «Капитала»: машина, недвижимость, вложения. Само не дешевеет и не дорожает — только по оценкам.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `name` | TEXT, обязательно | название |
| `kind` | TEXT, обязательно | вид имущества; значения: `vehicle`, `realty`, `equipment`, `investment`, `other` |
| `currency` | TEXT, обязательно | валюта оценок |
| `note` | TEXT | комментарий |
| `disposed_on` | TEXT | день продажи; с него имущество в «Капитале» стоит 0 |
| `sort` | INTEGER, обязательно | порядок в списках (меньше — выше) |

### `bank_conditions`

Условия банковского продукта: одна строка на счёт или на одну его карту. Пустая сумма — условие не указано, нулём она не читается.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `payment_method_id` | TEXT, обязательно | счёт; ссылка на `payment_methods`, строка уходит вместе со счётом |
| `card_id` | TEXT | карта счёта; пусто — условия самого счёта; ссылка на `cards`, строка уходит вместе с картой |
| `currency` | TEXT, обязательно | код валюты сумм (три заглавные латинские буквы) |
| `free_cash_e4` | INTEGER | сколько наличных в месяц снимается без комиссии |
| `free_sbp_e4` | INTEGER | сколько в месяц переводится по СБП без комиссии |
| `free_interbank_e4` | INTEGER | сколько в месяц переводится в другие банки без комиссии |
| `service_free_spend_e4` | INTEGER | трата за месяц, при которой обслуживание бесплатно |
| `service_free_balance_e4` | INTEGER | остаток, при котором обслуживание бесплатно |
| `min_balance_e4` | INTEGER | остаток, который продукт просит держать |
| `note` | TEXT | заметка свободным текстом |

### `banks`

Банки. Банк стоит над счётом и картой и деньгами не владеет: остатки, операции и сверки — у счёта.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `name` | TEXT, обязательно | название |
| `sort` | INTEGER, обязательно | порядок в списках (меньше — выше) |
| `archived` | INTEGER, обязательно | 1 — в архиве: не предлагается, но остаётся в операциях и отчётах |

### `budget_month_exceptions`

Лимит на один месяц: «Подарки» — 5 000 ₽, а в декабре — 20 000 ₽. В январе лимит сам возвращается к обычному. Одно исключение на лимит и месяц; если два устройства добавили свои, действует последнее.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `budget_id` | TEXT, обязательно | лимит; ссылка на `budgets`, исчезает вместе с ним |
| `month` | TEXT, обязательно | месяц, `YYYY-MM` |
| `amount_e4` | INTEGER, обязательно | лимит этого месяца, не меньше нуля |

### `budgets`

Лимиты на категории (и на «для кого»): сколько можно потратить за месяц.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `scope` | TEXT, обязательно | на что лимит: категория, все плохие траты или «для кого»; значения: `category`, `bad_total`, `for_whom` |
| `category_id` | TEXT | категория лимита; ссылка на `categories` |
| `for_whom` | TEXT | значение «для кого» (для лимита плохих трат и «для кого»); значения: `me`, `partner`, `friends`, `family`, `other` |
| `amount_e4` | INTEGER, обязательно | сумма лимита за месяц, в рублях |
| `rollover` | INTEGER, обязательно | 1 — остаток переносится на следующий месяц |
| `start_month` | TEXT | с какого месяца лимит действует, `YYYY-MM` |

### `cards`

Карты внутри счёта. Деньги и остаток — у счёта; карта держит свои имена и отличия правил кэшбэка.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `payment_method_id` | TEXT, обязательно | счёт, которому принадлежит карта; ссылка на `payment_methods` |
| `name` | TEXT, обязательно | название |
| `aliases` | TEXT, обязательно | другие названия, которые читает строка ввода (через запятую) |
| `sort` | INTEGER, обязательно | порядок в списках (меньше — выше) |
| `archived` | INTEGER, обязательно | 1 — в архиве: не предлагается, но остаётся в операциях и отчётах |
| `fx_fee_e4` | INTEGER | комиссия банка за конвертацию покупки за границей, в 1/10 000 процента (1,5 % — 15000); пусто — условия не заведены |
| `atm_fee_percent_e4` | INTEGER | процент комиссии за снятие наличных за границей, в той же единице |
| `atm_fee_fixed_e4` | INTEGER | фиксированная часть комиссии за снятие, в валюте `atm_fee_fixed_currency` |
| `atm_fee_fixed_currency` | TEXT | валюта фиксированной части комиссии за снятие |
| `last4` | TEXT | последние четыре цифры карты, по которым её узнаёт текст банка; пусто — не заведены |
| `details` | TEXT | всё остальное, что владелец хранит о карте, свободным текстом |
| `expires_on` | TEXT | последний месяц действия карты, `YYYY-MM`; пусто — не указан |

### `cashback_rules`

Правила кэшбэка счёта и отличия карт: процент на категорию, «всегда» или только в одном месяце.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `payment_method_id` | TEXT, обязательно | счёт, чьё это правило; ссылка на `payment_methods` |

| `month` | TEXT | месяц `YYYY-MM`, если правило только на месяц; пусто — «всегда» |
| `percent_e4` | INTEGER, обязательно | процент в десятитысячных долях процента (0–100 %) |

### `categories`

Дерево категорий: расходы и доходы, подкатегории. Системные категории (цели, кредиты, сверка и др.) защищены своей ролью.

| Столбец | Тип | Что это |
| --- | --- | --- |
| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `parent_id` | TEXT | родительская категория; пусто — верхний уровень; ссылка на `categories` |
| `kind` | TEXT, обязательно | доход или расход; значения: `expense`, `income` |
| `name` | TEXT, обязательно | название |
| `sort` | INTEGER, обязательно | порядок в списках (меньше — выше) |
| `archived` | INTEGER, обязательно | 1 — в архиве: не предлагается, но остаётся в операциях и отчётах |
| `quality` | TEXT | оценка по умолчанию: хорошая, обычная, плохая; значения: `good`, `neutral`, `bad` |
| `system_role` | TEXT | роль системной категории («Цели», «Кредиты», «Сверка», «Доплаты»…); пусто — обычная; значения: `goals`, `loans`, `unknown`, `surcharges` |
| `essential` | INTEGER | необязательная трата: 1 — необходимая, 0 — нет, пусто — как у родителя |
| `tax_rate` | TEXT | ставка налога с дохода в процентах (для самозанятых) |
| `tax_npd` | INTEGER, обязательно | 1 — налог на профессиональный доход (со вычетом и правилом 100 ₽), 0 — другая ставка |
| `basket` | TEXT | корзина бюджета: необходимое, желания, сбережения; значения: `needs`, `wants`, `savings`; пусто — у подкатегории как у родителя, у категории — по отметке «необходимая трата» |

### `transfers`

Переводы между своими счетами — не доход и не расход.

| Столбец | Тип | Что это |

| `id` | TEXT, ключ | идентификатор (UUID, текст) |
| `occurred_at` | TEXT, обязательно | когда это случилось (UTC) |
| `from_payment_method_id` | TEXT, обязательно | со счёта; ссылка на `payment_methods` |
| `from_currency` | TEXT, обязательно | валюта отправки |
| `from_amount_e4` | INTEGER, обязательно | сколько ушло |
| `to_payment_method_id` | TEXT, обязательно | на счёт; ссылка на `payment_methods` |
| `to_currency` | TEXT, обязательно | валюта получения |
| `to_amount_e4` | INTEGER, обязательно | сколько пришло |

| `updated_at` | TEXT, обязательно | момент последней правки (UTC) |
| `external_id` | TEXT | ключ переводов, которые пишет само приложение (`alloc:…`) |

Таблица `grdb_migrations` ведёт библиотека: в ней имена применённых миграций.

## Как прочитать копию без приложения

```sh
sqlite3 "2026-10-06 23.32 · 1.12.0 · ежедневная.sqlite" \
  "SELECT occurred_at, kind, amount_e4 / 10000.0, note FROM transactions WHERE deleted_at IS NULL ORDER BY occurred_at DESC LIMIT 20;"
```

Сумма операции равна сумме её частей (`transaction_parts`); расход «для кого» и «за другого» различаются столбцами части. Рядом с копией дня и копией «перед обновлением» лежит папка с теми же данными в CSV и `README.txt`.
