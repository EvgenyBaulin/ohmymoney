# Установка

## Требования

- macOS 26 (Tahoe) или новее: интерфейс построен на API Liquid Glass.

## Установка

Если вы пользовались прежним приложением, считайте OhMyMoney новым: его нужно скачать заново, прежнее
само в него не обновится. Данные переносятся копией базы: выберите в «Настройки → Бэкапы» папку
со свежей копией прежнего приложения и нажмите «Восстановить…».

1. Скачайте `OhMyMoney-<version>.zip` из
   [последнего выпуска](https://github.com/EvgenyBaulin/ohmymoney/releases/latest). Все выпуски — на
   странице [Releases](https://github.com/EvgenyBaulin/ohmymoney/releases).
2. Распакуйте его и перенесите `OhMyMoney.app` в **Программы** (/Applications). Не запускайте его из
   «Загрузок»: оттуда macOS запускает приложение из копии только для чтения, и модуль обновлений
   не может его заменить.
3. Откройте его. Выпуск подписан собственным сертификатом автора — не Developer ID — и не
   нотаризован, поэтому первый запуск будет заблокирован. Тогда откройте **Системные настройки →
   Конфиденциальность и безопасность** и нажмите **Всё равно открыть** рядом с сообщением об
   OhMyMoney. Достаточно одного раза.

   Или в Терминале снимите флаг карантина до первого запуска:

   ```sh
   xattr -dr com.apple.quarantine /Applications/OhMyMoney.app
   ```

4. При первом запуске OhMyMoney предлагает «Настройку счетов»: отметьте, где лежат деньги —
   банки России и Казахстана одним щелчком, наличные, любой другой счёт, — и сколько там сейчас,
   в какой валюте и в какой группе. Вписанный остаток станет первой сверкой счёта — точкой
   отсчёта, дальше остатки считаются сами; долг кредитной карты вписывается с минусом. Пустое
   поле — «не знаю»: такой счёт останется несверенным, и его первая сверка станет точкой
   отсчёта. «Позже» заводит «Основной счёт», а карточка в «Обзоре» вернёт к настройке.
