# Приватность и сеть

Ниже — адреса, к которым приложение обращается само, и причины запросов. Запрос возникает
только при указанном действии или настройке.

| Хост или адрес | Когда и зачем |
| ---- | ----- |
| `www.cbr.ru` | Основной источник курса валют Банка России на нужный день. Страницы ключевой ставки и средней максимальной ставки по вкладам читаются не чаще раза в сутки, только если включено «Брать ставки из открытых источников» (по умолчанию выключено). |
| `www.cbr-xml-daily.ru` | Зеркало курсов валют — только если основной источник Банка России не ответил. |
| `api.coingecko.com` | Курс вашей собственной валюты, только если для неё выбран источник CoinGecko. В параметрах запроса — лишь идентификатор монеты и рубли; источник можно сменить на «Вручную». |
| `www.banki.ru` | Публичная страница вкладов — только при включённом «Брать ставки из открытых источников», не чаще раза в сутки. Приложение не прикладывает cookies, счёт или сумму. Сейчас сайт отвечает защитной страницей, поэтому приложение не получает оттуда ставок. |
| `EvgenyBaulin.github.io` | Лента обновлений для обычной версии OhMyMoney для Mac, если в сборке доступна проверка: автоматически раз в день при включённой настройке или по вашей просьбе. |
| `github.com` и адрес доставки файлов, на который перенаправляет GitHub | Архив обновления из GitHub Releases, только если доступно новое обновление. |
| Адрес страницы, который вы указали в покупке | Один запрос страницы при нажатии «Взять со ссылки». Поддерживаются HTTP и HTTPS; приложение не отправляет куки и данные учётной записи, не следует перенаправлениям и не загружает картинки со страницы. |
| `oauth.yandex.ru`, `cloud-api.yandex.net` и выданный сервисом временный HTTPS-адрес | Вход в Яндекс.Диск и обмен зашифрованными файлами. Временный адрес используется только для передачи файла. |
| `www.dropbox.com`, `api.dropboxapi.com`, `content.dropboxapi.com` | Вход в Dropbox, получение токена и обмен зашифрованными файлами. |
| `login.microsoftonline.com`, `graph.microsoft.com` и выданный сервисом HTTPS-адрес загрузки | Вход в OneDrive и обмен зашифрованными файлами. Временный адрес используется для передачи больших файлов. |
| `accounts.google.com`, `oauth2.googleapis.com`, `www.googleapis.com` | Вход в Google Drive и обмен зашифрованными файлами в папке приложения. |
| `webdav.cloud.mail.ru` | Обмен зашифрованными файлами с Облаком Mail.ru по введённым вами данным входа. |
| Хост проекта Supabase, который вы указали | Обмен зашифрованными файлами с вашим проектом. Приложение принимает только HTTPS-адрес; ключ проекта хранится в связке ключей этого устройства. |

Запросы для входа в облако начинаются только после нажатия «Подключить», обмен файлами — после
подключения и выбора диска. Обменные файлы шифруются на устройстве до отправки.
Для Яндекс.Диска и OneDrive адрес передачи файла выдаёт сам сервис, поэтому он не является
постоянным адресом приложения. Серверы также могут перенаправлять запросы на адреса, которые
задают сами сервисы. Для страницы покупки перенаправления отключены.

iCloud Drive — это выбранная вами папка обмена. OhMyMoney читает и записывает в ней файлы, а их
синхронизацией занимается системная служба Apple; отдельного сетевого хоста iCloud в приложении
нет. Для папки на другом подключённом диске сетевой доступ также обеспечивает система.

Кнопка поддержки открывает `pay.cloudtips.ru` в браузере, а в версии из App Store пункт обновления
открывает страницу OhMyMoney в App Store (`apps.apple.com`). Сетевые запросы после этого выполняет
браузер или App Store. В версии из App Store собственного механизма обновления нет.
Ссылки из пожеланий и напоминаний приложение открывает во внешнем приложении только по вашему
нажатию; их адреса задаёте вы.

Телеметрии, аналитики и учётной записи OhMyMoney нет. Собственный журнал приложения (для отчёта о
проблеме, который вы решите отправить) хранит идентификаторы, счётчики и типы ошибок и никогда
не хранит сумм, заметок, людей, мест или названий категорий: это проверяют автоматические тесты.
