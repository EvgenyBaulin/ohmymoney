# Приватность и сеть

OhMyMoney обращается только к адресам из таблицы и только по этим причинам:

| Хост | Зачем |
| ---- | ----- |
| `www.cbr.ru` | курсы валют Банка России на нужный день |
| `www.cbr-xml-daily.ru` | зеркало тех же курсов — когда банк не отвечает |
| `EvgenyBaulin.github.io`, `github.com` | лента обновлений и архивы новых версий |
| `api.coingecko.com` | курс монеты в рублях, только если вы завели свою валюту с источником «из сети»: в запросе лишь идентификатор монеты и валюта (рубли), ничего о вас; выключается в «Настройки → Валюты → Курс криптовалют → Вручную» |
| `www.cbr.ru` (страница `statistics/avgprocstav`) | «По данным Банка России» в «Витрине вкладов» — средняя максимальная ставка десяти банков, только если вы включили «Брать ставки из открытых источников» (по умолчанию выключено): раз в сутки один запрос публичной страницы, без куки и без данных о вас |
| `www.banki.ru` | тот же переключатель; сайт отдаёт программе только защитную страницу, поэтому ставок оттуда приложение не берёт и список остаётся прежним |

Телеметрии, SDK аналитики и учётной записи нет. Собственный журнал приложения (для отчёта о
проблеме, который вы решите отправить) хранит идентификаторы, счётчики и типы ошибок и никогда
не хранит сумм, заметок, людей, мест или названий категорий; если что-то из этого туда попадёт,
упадёт тест. Сборка для App Store вовсе не содержит модуля обновлений и обращается только к
Банку России и, для своих монет, к CoinGecko.
